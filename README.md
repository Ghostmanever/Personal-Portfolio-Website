# Aryan Kaushal - Personal Portfolio

A clean, minimal, dark-themed portfolio website built with pure HTML and CSS.

## Preview

This portfolio showcases Aryan Kaushal - an aspiring Robotics Engineer based in Riga, Latvia, with certifications in RHCSA, RHCE, CEH, and a background in competitive gaming.

## Features

- **Dark Mode Design** - Sleek dark theme with blue accent colors
- **Fully Responsive** - Optimized for mobile, tablet, and desktop
- **Pure HTML & CSS** - No JavaScript frameworks or dependencies
- **SVG Icons** - Clean vector icons for contact links
- **Smooth Animations** - Subtle hover effects and transitions

## Sections

1. **Hero** - Logo, name, title, and call-to-action
2. **About** - Brief professional summary
3. **Skills** - Technical competencies in a grid layout
4. **Contact** - Social links with icons (Email, GitHub, YouTube, Location)
